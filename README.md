# 🏕️ CampMaster Pro v3.0.0 (PWA)

แอปสายแคมป์ปิ้ง ติดตั้งลงมือถือได้ ใช้ออฟไลน์ได้ ไม่พึ่ง CDN

## ฟังก์ชัน
- ลานกางเต็นท์: ค้นหา/กรอง เรียงตามระยะใกล้ฉัน ปุ่มชอบ นำทาง Google Maps และ **เพิ่มลานของตัวเอง**
- อากาศ (Open-Meteo): ตอนนี้ + 4 วัน, ลมกระโชก, โอกาสฝน, เวลาพระอาทิตย์ตกจริง, เก็บค่าล่าสุดไว้ดูออฟไลน์
- จัดของ: ติ๊ก/เพิ่ม/ลบ, ชุด Car/Moto, บันทึกในเครื่อง
- คำนวณไฟ: เลือกอุปกรณ์แล้วรวมวัตต์ให้
- SOS: พิกัด GPS + ลิงก์แผนที่, เสียงมอร์ส, ไฟกระพริบ, เบอร์ฉุกเฉิน
- เมนู: ตรวจสอบอัปเดต, ติดตั้งแอป

## ขึ้น GitHub Pages
อัปโหลดทุกไฟล์ (รวมโฟลเดอร์ `icons/`) ไว้ที่ root ของ repo แล้วเปิด Settings > Pages (ต้องเป็น https ถึงจะติดตั้ง/อัปเดตได้)

## ออกอัปเดตเวอร์ชันใหม่
1. แก้ไฟล์ที่ต้องการ
2. เปลี่ยน `VERSION` ใน `sw.js` (เช่น 3.0.1) และ `VER` ใน `index.html`
3. อัปโหลดทับ → ผู้ใช้จะเห็นแถบ "มีเวอร์ชันใหม่" แล้วกดอัปเดต (แอปตรวจเองทุก 30 นาทีและทุกครั้งที่เปิดกลับมา)
